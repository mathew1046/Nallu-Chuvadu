# Nalla Chuvadu — The Positive Quest

A PHP and MySQL web app that turns small acts of kindness into a daily quest.

## Run locally

1. Create a MySQL database and import `database.sql`.
2. Update database credentials in `config.php`.
3. Serve this folder through Apache/PHP (or run `php -S localhost:8000` if PHP is installed).
4. Register a member account. To make an administrator, set `role = 'admin'` for that account in MySQL.

The included starter tasks cover environmental action, neighbours, learning, food sharing, and donations.
